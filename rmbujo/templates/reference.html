Using this journal

Start a month: set up the day list and the Tasks page, then migrate open items forward from last month and the Future Log.

End a month: review each day and the Tasks page. Complete (×), migrate (>) unfinished tasks to next month, or schedule (<) them into the Future Log. Drop what no longer matters.
